# Verificador de texto

Leia `comum.md` primeiro, mas ignore tipo e peso.

Para cada fato, confira palavra por palavra se o `titulo` e a `frase` estão sustentados pelos `trechos`: cada número, cada data, cada quem-fez-o-quê. Uma afirmação sem apoio no trecho derruba o item. Definições de dicionário: responda `"sustenta": true`.

Saída, uma lista na ordem do lote:

```json
[{"rotulo": "F4821", "sustenta": true, "motivo": "até 25 palavras"}]
```
